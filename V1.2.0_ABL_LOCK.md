## Locked reliability/data changes

- 32 logarithmic coarse spectral bins from 20 Hz to the available upper bound (up to 20 kHz).
- Spectral definition identifier: `log32-slope-v1`.
- Add spectral slope computed by linear regression across the 32 normalized coarse-spectrum bins.
- Keep five per-band spectral contrast/crest-style diagnostic features already approved by the technical design; do not fabricate time-domain band crest factor without the required filter-bank pipeline.
- `analysisTimestamp` records when processing completed (or a trustworthy imported source timestamp when one exists).
- `createdAt` records when the version record was written to IndexedDB.
- `fileHash` is SHA-256 of the actual audio bytes. Filenames, file size, and modification time are not the deduplication hash.
- No source audio bytes/blobs/PCM are persisted or uploaded.

## Migration safety

- Mandatory legacy dry-run before import.
- Save legacy payload in IndexedDB under `_legacy_backup` before migration.
- Store SHA-256 of the backup payload and validate it after migration.
- Import project/song/version/meta records in one multi-store IndexedDB transaction.
- Validate migrated record count, required fields, schema/origin markers, project/song presence, and backup hash.
- If validation or migration fails, restore the legacy payload and defensively remove imported records/markers.
- Keep the backup through successful validation and remove it automatically after the next confirmed clean launch; no manual user-confirmation gate.

## IndexedDB reliability

- All application IndexedDB access is routed through the centralized storage service.
- Every write retries up to three times using 100 ms, 500 ms, and 2 s delays.
- After retries are exhausted, show: `Unable to save due to storage constraints. Please close other tabs and try again.`
- Storage failures are logged locally only and are never uploaded.
- Preserve 60% / 80% / 90% storage quota warning thresholds when a usable browser quota is reported.
- `navigator.storage.estimate()` is treated as a browser-origin estimate and may be fuzzy/unavailable on iOS.
