## Objective
Build the first professional metering layer on top of the proven v1.2 analysis, recovery, room-signature, Mix-Diff, and IndexedDB foundation without removing or weakening existing functionality.

## Scope
1. ITU-R BS.1770 / EBU Tech 3341 aligned loudness engine:
   - Momentary loudness: 400 ms sliding window.
   - Short-term loudness: 3 s sliding window.
   - Integrated loudness: 400 ms blocks, 75% overlap, -70 LUFS absolute gate, -10 LU relative gate.
   - K-weighting adapted to the active Web Audio sample rate.
2. True-peak foundation:
   - Inter-sample peak estimation at >=4x effective resolution for common 44.1/48 kHz sources.
   - Display method/compliance status honestly until validated against the official EBU/ITU minimum-compliance test set.
3. Stereo diagnostics:
   - Stereo correlation from -1 to +1.
   - Lightweight vectorscope points for a real-time goniometer.
   - Mono-safe behavior when only one channel is available.
4. Input diagnostics:
   - Actual Web Audio sample rate.
   - Channel count.
   - Sample peak.
   - DC offset estimate.
   - Dropout / near-silence transition detection.
5. Architecture:
   - Heavy per-sample metering in AudioWorklet where supported.
   - Existing AnalyserNode remains for the current spectrum UI.
   - Graceful fallback keeps v1.2 analysis operational if AudioWorklet is unavailable.
   - New modules remain isolated from recovery/export code.
6. Persistence:
   - Extend v1.2 version records with a sanitized `professionalMetering` object.
   - No raw PCM/audio blobs persisted or uploaded.
7. UI:
   - Professional Metering card with M/S/I loudness, true-peak estimate, correlation, vectorscope, and input diagnostics.
   - Microphone capture must clearly state that LUFS describes the captured acoustic chain, not mastering/program loudness.
   - Do not claim calibrated dB SPL without a calibrated measurement microphone/profile.

## Truth / Safety Constraints
- Never label an uncalibrated phone-microphone reading as absolute SPL or Leq SPL.
- Never call an interpolation-only inter-sample peak value fully standards-compliant true peak until the official compliance suite passes.
- LUFS from a microphone is a captured-signal loudness measurement and must not be represented as source-file mastering loudness.
- No fabricated stereo data for mono inputs.
- No fabricated measurements when a browser does not expose the required audio data.
- No source audio, PCM, or microphone recordings persisted or uploaded.

## QA Gate
- Pure unit tests for K-weighting coefficients, LUFS gating, correlation, true-peak interpolation, mono handling, DC offset, and dropout logic.
- Regression tests for v1.2 spectral/runtime/migration/recovery features.
- Browser test confirms AudioWorklet path when supported and v1.2 fallback when unavailable.
- Shell contains each v1.3 module exactly once.
- Service-worker registration remains absent.
- Vercel deployment remains disabled throughout build/QA.

## Out of Scope for v1.3
- Calibrated SPL/Leq SPL claims.
- Spectrogram / WebGL renderer (v1.4).
- Reference-track A/B loudness matching (v1.5).
- Automated room correction EQ (v1.6).
- Persisting source audio.
